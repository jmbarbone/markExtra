# Changelog

## markExtra (development version)

- adds
  [`passcode()`](https://jmbarbone.github.io/markExtra/reference/passcode.md)
  for generating fun, easy to remember passcodes
- adds
  [`array_extract()`](https://jmbarbone.github.io/markExtra/reference/array_extract.md)
  and
  [`simpleTimeReport()`](https://jmbarbone.github.io/markExtra/reference/simpleTimeReport.md)
  from [`{mark}`](https://github.com/jmbarbone/mark)

## markExtra 0.1.3

- adds
  [`weighted_score()`](https://jmbarbone.github.io/markExtra/reference/weighted_score.md)

## markExtra 0.1.2

- corrects issue with
  [`autoplot_table_mosaic()`](https://jmbarbone.github.io/markExtra/reference/autoplot_table_mosaic.md)
  [(#6)](https://jmbarbone.github.io/markExtra/news/github.com/jmbarbone/markExtra/issues/6)
- adds experimental
  [`cache()`](https://jmbarbone.github.io/markExtra/reference/cache.md)
- adds
  [`autoplot_table_mosaic()`](https://jmbarbone.github.io/markExtra/reference/autoplot_table_mosaic.md)
  for making mosaic plots from tables
- adds
  [`min_max()`](https://jmbarbone.github.io/markExtra/reference/min_max.md)
  normalization

## markExtra 0.1.1

- changes package name to `markExtra`
  [(#2)](https://jmbarbone.github.io/markExtra/news/github.com/jmbarbone/markExtra/issues/2)
- moves startup functions to separate package
  [(#1)](https://jmbarbone.github.io/markExtra/news/github.com/jmbarbone/markExtra/issues/1)
- props moved to
  [`jordan::proportions()`](https://github.com/jmbarbone/mark/blob/main/R/counts.R)
